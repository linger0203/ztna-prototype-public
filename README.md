# ZTNA 管控台原型（公网演示版）

SAG 零信任安全服务平台的管控台高保真原型。**单文件 HTML，双击即开，不需要起服务、不需要装环境。**

## 怎么看

**在线看（推荐，手机也能开，无需登录）**

https://linger0203.github.io/ztna-prototype-public/

> 首次访问如果 404：到仓库 Settings → Pages，Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等 1 分钟。

**本地看**

```bash
git clone git@github.com:linger0203/ztna-prototype-public.git
```

双击 `index.html`。

## 注意

仓库根目录的 `.nojekyll` 不要删。GitHub Pages 默认走 Jekyll，会跳过 `_assets` 这类下划线开头的目录，删了它样式、图表、图标会全部 404。

## 这是什么

- 覆盖 ZTNA 管控台的完整页面：应用与资源发布、网络与 SDP、安全策略、终端管理、系统与审计等，共 55 页
- 页面可点、表单可填、状态可切，用于需求评审与联调对齐，**不是可运行的产品**
- 数据全部为演示数据：域名统一 `*.example.com`，IP 为私有网段示例，无任何真实客户信息

## 给研发 / 测试

- 页面路由、字段、列顺序以原型为准；有疑问时以原型 + 需求文档对齐，不要反过来按代码猜
- 关键交互可以直接点：应用画像的模块清单可展开、可改名、可设主 API；请求列表可筛选、去噪；发布/取消发布有完整状态流转
- 发现原型本身的问题（点不动、文案歧义、状态缺失）请提 issue，写清**页面 + 操作路径 + 期望结果**

## 说明

这个仓库只放**可运行的原型成品**。完整工程（页面引擎、各模块配置、构建注入脚本、自检与截图脚本）在公司内部私有仓库维护，不在此公开。

原型内品牌与产品名称已保留，业务数据已脱敏，可对外演示。
